# Guia de Rust

Este espaço reúne a trilha de aprendizado da linguagem, com exemplos executáveis e referências para quem vem de TypeScript.

O pacote `guia-rust` contém exemplos registrados em `Cargo.toml`. Para executar o exemplo inicial de empréstimo mutável, preservado do experimento original:

```sh
cargo run -p guia-rust --example emprestimo_original
```

As ferramentas de terminal ficam em [ferramentas/](../ferramentas/README.md).
