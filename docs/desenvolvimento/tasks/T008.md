# T008 — Contratos exatos para pontos de extensão

Status: **concluída** · Prioridade: **P1**

Dependências: [T001](T001.md)

## Entrega

Fazer o helper integrations::replace rejeitar âncoras ausentes ou duplicadas e revisar as substituições silenciosas próximas.

## Critérios de conclusão

- Mudança de template retorna Error identificando arquivo/âncora, sem panic.
- Uma âncora duplicada não altera apenas a primeira ocorrência silenciosamente.
- Testes de falha demonstram que nenhum destino foi publicado.

## Verificação

cargo test -p rust-boilerplate --locked; caso de template com âncora duplicada.

## Evidência

- replace exige âncora literal não vazia com exatamente uma ocorrência, incluindo detecção de sobreposição. A falha retorna Error operacional com arquivo/âncora/contagem sem modificar o texto.
- Adicionados source_mut e anchor_position para reportar fontes/âncoras ausentes sem panic nesses pontos de extensão.
- Migradas as substituições silenciosas dos testes Node/Python, o recorte inicial do repository Nest e as inserções no Dockerfile Rust para os contratos verificados.
- Testes cobrem âncora ausente, duplicada, sobreposta, vazia e fonte ausente. O renderer foi exercitado com quatro corrupções de assets Express/Nest; nenhuma publicou diretório ou staging.
- sh scripts/check-workspace.sh --offline passou: 59 testes, fmt, doctests e Clippy.
- Comparadas 12 gerações completas antes/depois (quatro stacks × nenhum/PostgreSQL/MongoDB, com cache/métricas/Vault/infra): arquivos idênticos byte a byte.
- Recortes de funções e composição em strings ainda existentes no adapter Rust pertencem à T010; a entrega não altera contratos HTTP ou dependências.
