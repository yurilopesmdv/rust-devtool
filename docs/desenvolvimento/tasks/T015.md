# T015 — Contrato JSON para falhas operacionais

Status: **concluída** · Prioridade: **P1**

Dependências: [T001](T001.md)

## Entrega

Definir/implementar um envelope estável para falhas de new --json.

## Critérios de conclusão

- Inclui código, etapa e diretórios já criados, sem segredos.
- stdout continua parseável; logs externos ficam em stderr.
- Testes cobrem instalação ausente, Git indisponível e falha após publicação.

## Verificação

Testes CLI com ferramentas simuladas e parser JSON.

## Evidência

- Envelope versão 1 em new --json após parsing: ok, created e error com code/stage/kind/exit_code. Sucesso preserva campos existentes e adiciona versão/ok.
- Progresso acompanha validação/render/publicação/Git/instalação/GitHub. Raízes publicadas são preservadas e reportadas em falhas posteriores; mensagens/argumentos de terceiros não entram no envelope.
- Teste CLI com PATH isolado cobre Git ausente antes da publicação, Git com falha após publicação e uv ausente na instalação. JSON parseável, fontes preservadas e stdout sem logs/segredo de teste.
- Workspace completo aprovado; contrato e limites de parsing/carregamento/encerramento forçado documentados no guia de agentes.
