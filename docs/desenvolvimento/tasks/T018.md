# T018 — Smoke test das imagens Docker

Status: **implementada; execução com daemon pendente** · Prioridade: **P2**

Dependências: [T003](T003.md), [T004](T004.md), [T005](T005.md)

## Entrega

Adicionar validação opt-in de build/start/readiness das imagens mínimas.

## Critérios de conclusão

- Roda apenas com daemon de teste; não muda o comportamento de new.
- Verifica usuário não root, arquivos necessários e encerramento.
- Remove somente recursos próprios do teste; mantém volumes externos intactos.

## Verificação

Job dedicado com labels/prefixo exclusivo e cleanup em finally/trap.

## Evidência

Runner opt-in para oito bases e matriz workflow_dispatch (desativada por padrão) implementados. Verifica UID/arquivo/readiness/encerramento e usa nomes/labels exclusivos com cleanup exato, sem volumes/prune. Testes simulam sucesso e falha de readiness e comprovam cleanup; 23 testes de manutenção, Ruff e actionlint aprovados. O daemon Docker não está disponível neste ambiente; não foi iniciado/instalado e nenhuma imagem foi anunciada como validada em runtime. A execução real fica a cargo do job manual em runner descartável.

## Retomada da validação

Preflight local confirmou daemon do sistema inativo. Docker rootless está presente, mas falta newuidmap/newgidmap para o mapeamento; nenhuma instalação global foi realizada. Preparada execução em branch validation/docker-* para validar imagens em runner descartável antes da integração na main. Publicação e run remoto ainda não realizados.

Readiness agora repete tentativas após reset de conexão e preserva o erro principal quando cleanup também falha. Três regressões adicionadas; suíte de manutenção com 28 testes aprovada.
