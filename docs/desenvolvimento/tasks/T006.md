# T006 — CI de persistência com serviços descartáveis

Status: **concluída; execução remota aprovada** · Prioridade: **P1**

Dependências: [T003](T003.md), [T004](T004.md), [T005](T005.md)

## Entrega

Adicionar job separado para APIs com PostgreSQL/MongoDB/Redis de teste e --with-services.

## Critérios de conclusão

- Credenciais somente de teste; nenhum serviço pessoal ou cloud.
- Preparação explícita e leitura/escrita verificadas; readiness indisponível também exercitada.
- Suíte sem URLs não é anunciada como teste de persistência; serviços são encerrados.

## Verificação

Rodar validate-generated.py --with-services com URLs dedicadas e observar os testes habilitados.

## Evidência local anterior à execução remota

- Job generated-persistence tem cinco entradas (Express ESM/CommonJS, Nest, FastAPI e Axum), cada uma com PostgreSQL 17.6, MongoDB 8.0.13 e Redis 7.4.5 descartáveis, health checks e timeout de 30 minutos.
- Dados/credenciais do workflow são exclusivos de teste. Os services são geridos pelo ciclo de vida do job, sem cloud ou serviços pessoais.
- Templates de teste agora verificam /ready=200 com conexão aberta, /ready=503 depois de fechar a conexão e /health=200 no mesmo processo. A rota de fechamento Python existe apenas no app em memória criado no teste.
- Dez combinações executadas localmente com --with-services: quatro stacks × dois bancos e Express/CommonJS × dois bancos. Preparação explícita, lint/formato, leitura/escrita, invalidação e falha de readiness passaram; Redis real estava autenticado.
- Usados PostgreSQL 17.6, Redis 7.4.5 e MongoDB 7.0.14, compatível com este host. Os processos isolados foram encerrados em finally, inclusive em falhas.
- Docker não tem daemon acessível nesta máquina: não foram executadas as imagens de service do workflow. MongoDB 8 e o job remoto continuam pendentes do primeiro run no GitHub.
- actionlint 1.7.12, Ruff do fragmento Python e sh scripts/check-workspace.sh --offline passaram (55 testes do workspace).
- Python declara app como first-party no isort para manter a mesma ordenação nos fragmentos e no projeto gerado.
