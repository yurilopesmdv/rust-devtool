Node/Express, Node/Nest, Python/PyMongo e Rust/Mongo passaram contra MongoDB 7.0.14 standalone autenticado temporário. Testes reais: bootstrap/up repetido, alteração indevida de arquivo, falha no segundo documento de backfill, checkpoint 1 preservado, reparo de dados e retomada até checkpoint 3, duas execuções concorrentes, reserva preexistente não removida e unlock com owner incorreto/correto. URL por arquivo tem prioridade sobre a URL da aplicação.

Node passou npm lint/format/typecheck/build; Python passou uv --locked e Ruff; Rust compilou o binário nativo e passou fmt/Clippy. Nenhuma dependência de Node foi adicionada aos executores Rust/Python, e nenhum grafo Cargo/uv/npm precisou mudar. Teste de geração garante omissão quando desativado e preservação de cargo run da API via default-run.

Workspace completo, 31 testes de manutenção, actionlint e links aprovados. Job Native Mongo migrations preparado com MongoDB 8.0.13 descartável; execução remota desta alteração ainda pendente. A CI anterior da M001 foi aprovada: Quality 40552648239, commit 9a5c52d. Também foi corrigida/testada a prioridade da URL PostgreSQL por arquivo nas cinco stacks.

Escopo inicial: operações declarativas bootstrap_examples/copy_field em examples (M003 acrescenta contract/recuperação); não há transação entre documentos, TTL de reserva, reset de histórico ou Job automático de migrations.
