# T016 — Uniformizar limites Unicode dos contratos HTTP

Status: **concluída** · Prioridade: **P2**

Dependências: [T003](T003.md), [T004](T004.md), [T005](T005.md)

## Entrega

Alinhar a contagem de caracteres de message entre Node, Rust e Python.

## Critérios de conclusão

- 200 caracteres Unicode aceitos e 201 rejeitados em todas as APIs.
- Entrada não string continua inválida; preservar códigos HTTP documentados por framework.
- Teste usa caracteres fora de ASCII e restaura dados de teste.

## Verificação

Rodar casos HTTP nas quatro APIs.

## Evidência

- Node conta pontos de código via Array.from em Express/Nest; Rust chars e Python/Pydantic já seguiam esse contrato. Documentado que não se trata de grafemas visuais.
- Casos HTTP persistentes aceitam 200 emojis, rejeitam 201 e entrada numérica; restauram a mensagem anterior. Rust agora verifica escrita via HTTP em fragmento legível e restaura antes de comparar resultados.
- Dez combinações reais passaram: Express/Nest/Rust/Python × PostgreSQL/MongoDB e Express CommonJS × dois bancos. Lint/formatação/build/test dos projetos e checks Compose/Kustomize aprovados; serviços temporários encerrados.
- Ruff detectou uma linha longa no novo teste Python; corrigida antes da repetição dos seis casos restantes. Os quatro casos Node já aprovados não foram repetidos sem necessidade.
- Workspace completo, 22 testes de manutenção e links Markdown aprovados.
