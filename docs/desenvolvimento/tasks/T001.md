# T001 — Comando único de validação do workspace

Status: **concluída** · Prioridade: **P0**

Dependências: nenhuma

## Entrega

Criar scripts/check-workspace.sh em POSIX sh, executável a partir de qualquer diretório, com modo offline e falha imediata.

## Critérios de conclusão

- Executa fmt, testes de todos os targets, doctests e Clippy com warnings como erro.
- Testes/Clippy usam Cargo.lock sem atualizá-lo; --offline não consulta rede.
- Ajuda e argumentos inválidos não executam Cargo; erros preservam o código de saída.

## Verificação

sh scripts/tests/check-workspace.sh; sh scripts/check-workspace.sh --offline

## Evidência

- `sh -n scripts/check-workspace.sh scripts/tests/check-workspace.sh`: passou.
- `sh scripts/tests/check-workspace.sh`: ajuda, argumentos inválidos, execução fora da raiz, caminhos com espaços, modo offline e preservação do código de erro passaram.
- `sh scripts/check-workspace.sh --offline`: fmt, 55 testes, doctests e Clippy passaram no WSL/Linux. A biblioteca ainda não contém doctests executáveis; a etapa está preparada para eles.
- Cargo.lock permaneceu sem alterações. Nenhuma instalação global ou execução de infraestrutura foi feita.

Entrega: scripts/check-workspace.sh, scripts/tests/check-workspace.sh e CONTRIBUTING.md. O CI usa uma task própria (T002).
