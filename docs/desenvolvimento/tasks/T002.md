# T002 — CI do núcleo usando o mesmo comando

Status: **pendente** · Prioridade: **P0**

Dependências: [T001](T001.md)

## Entrega

Versionar um workflow GitHub Actions para PRs, push em main e execução manual.

## Critérios de conclusão

- Executa testes do script e o comando local; não duplica a lista de checks.
- Checkout fixado por SHA, token somente leitura, credenciais não persistidas e timeout.
- Workflow validado localmente; registrar separadamente a primeira execução real no GitHub.
