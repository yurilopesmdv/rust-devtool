# T002 — CI do núcleo usando o mesmo comando

Status: **implementada; execução remota pendente** · Prioridade: **P0**

Dependências: [T001](T001.md)

## Entrega

Versionar um workflow GitHub Actions para PRs, push em main e execução manual.

## Critérios de conclusão

- Executa testes do script e o comando local; não duplica a lista de checks.
- Checkout fixado por SHA, token somente leitura, credenciais não persistidas e timeout.
- Workflow validado localmente; registrar separadamente a primeira execução real no GitHub.

## Verificação

actionlint .github/workflows/quality.yml; sh scripts/check-workspace.sh --offline

- Entrega: `.github/workflows/quality.yml`, com PRs, push em main e workflow_dispatch.

- O workflow chama o wrapper e o comando da T001, ambos validados localmente; não mantém uma segunda lista de checks Cargo.
- Checkout v7.0.1 foi resolvido no repositório oficial e fixado no commit 3d3c42e5aac5ba805825da76410c181273ba90b1. Token contents:read, persist-credentials:false, timeout de 20 minutos e cancelamento de execuções antigas.
- CI usa Rust stable e registra rustc/cargo no log. A política de versões/atualizações é uma entrega separada (T020).
- **Primeiro run no GitHub ainda não executado.** Os arquivos estão preparados para o próximo envio/PR. Verificar o resultado remoto antes de anunciar esse gate como operacional.
