Adapter Go/PostgreSQL com pgx v5.11.0 fixado em snapshots go.mod/go.sum. Pool com startup ping/limites e fechamento após shutdown; service injeta interface, repository contém SELECT/upsert parametrizados, preparação explícita em cmd/prepare. Base none continua sem driver/repository/go.sum.

Servidor compilado também respondeu /ready 200 e encerrou com SIGTERM/exit 0 contra PostgreSQL autenticado temporário; ambos encerrados em finally.

Compose config e Kustomize passaram. Imagem contém prepare somente quando selecionado; Job usa /app/prepare. Go incluído no smoke opt-in e CI com PostgreSQL descartável, ainda sem execução remota/daemon Docker. Workspace completo, 25 testes de manutenção, Ruff, actionlint e links válidos. Mongo/Redis/Vault/monitoria continuam rejeitados no catálogo.
