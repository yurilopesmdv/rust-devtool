# T023 — CI opcional nos projetos gerados

Status: **concluída; workflow gerado validado localmente** · Prioridade: **P3**

Dependências: [T003](T003.md), [T004](T004.md), [T005](T005.md)

## Entrega

Desenhar uma opção explícita de CI por stack e implementar primeiro um backend.

## Critérios de conclusão

- Omitida quando desativada; sem publicação/deploy automático.
- Receita registra a escolha e descreve limites de permissão.
- Workflow chama os mesmos checks locais do projeto gerado.

## Verificação

Gerar com/sem CI e validar o workflow e o comando local.

## Evidência

Opção --ci none/github-actions e pergunta opt-in Express, registrada na receita. Catálogo limita a Express; outras stacks falham no plano antes da escrita. Workflow omitido quando desativado; monorepo usa apps/api e split publica somente na API, removendo CI da receita frontend.

Testes de geração cobrem três layouts com/sem CI e stack incompatível. Projeto real temporário com CI passou npm ci, npm run check e actionlint; workspace completo aprovado. Workflow usa actions com SHA, contents:read e credenciais desativadas, sem deploy/publicação. Documentação informa testes de persistência condicionais e required checks separados. Nenhuma execução GitHub foi disparada.
